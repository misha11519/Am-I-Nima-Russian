# Русификатор Am I Nima

Русификатор для игры **Am I Nima**, полностью построенный на базе **BepInEx** и **Harmony**.

> **Предупреждение:** перевод текста выполнен с помощью **ИИ**, поэтому в диалогах, интерфейсе или ключевых словах возможны неточности, опечатки, расхождения по контексту или шероховатости формулировок.

## Установка
1. Скачайте архив **`Am-I-Nima-Russian.zip`** со страницы [Releases](https://github.com/misha11519/Am-I-Nima-Russian/releases).
2. Распакуйте содержимое архива в корневую папку игры (туда, где находится `Am I Nima.exe`).
3. Запустите игру и выберите **Русский** в настройках языка.
