# Русификатор Am I Nima

Неофициальный русификатор для игры **Am I Nima** версии **1.0.4** на базе BepInEx.

> **Примечание:** перевод выполнен с помощью ИИ, поэтому в некоторых диалогах и фразах возможны неточности или стилистические шероховатости.

## Установка
1. Скачайте архив **`Am-I-Nima-Russian.zip`** из раздела [Releases](../../releases/latest).
2. Откройте папку с установленной игрой:
   * В Steam: ПКМ по игре → *Управление* → *Посмотреть локальные файлы*
   * Стандартный путь: `C:\Program Files (x86)\Steam\steamapps\common\Am I Nima`
3. Распакуйте содержимое архива прямо в корневую папку игры, где находится `Am I Nima.exe`.
4. Запустите игру. При необходимости выберите **Русский** в настройках языка.

## Удаление
Удалите из папки игры папку `BepInEx` и файлы `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`.
